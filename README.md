# LMS

Backend-проект онлайн-обучения на Django REST Framework.

## Запуск проекта

Для запуска необходимы:

* Docker
* Docker Compose

### 1. Настройка переменных окружения

Создайте файл `.env` в корне проекта и укажите необходимые переменные окружения.

### 2. Запуск

Для сборки образов и запуска всех сервисов выполните:

```bash
docker compose up --build
```

При запуске автоматически выполняются миграции базы данных.

После запуска приложение доступно по адресу:

http://127.0.0.1:8000/

В проекте запускаются следующие сервисы:

* Django — веб-приложение;
* PostgreSQL — база данных;
* Redis — брокер сообщений и кэш;
* Celery — выполнение фоновых задач;
* Celery Beat — выполнение периодических задач;
* отдельный сервис миграций Django — автоматическое применение миграций базы данных.

### Остановка

Для остановки контейнеров нажмите `Ctrl+C`.

Для остановки запущенных в фоне контейнеров используйте:

```bash
docker compose down
```

### Запуск в фоновом режиме

```bash
docker compose up -d
```

Для просмотра логов:

```bash
docker compose logs -f
```

### Остановка с удалением volumes

```bash
docker compose down -v
```

> Команда `docker compose down -v` удаляет Docker volumes, в том числе volume с базой данных. Используйте её только если данные базы больше не нужны.
